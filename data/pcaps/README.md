# Packet captures

These original PCAP and PCAPNG files are a verified retrieval cover for the six-protocol training and benchmark inputs described in the paper. Matching bytes do not establish which duplicate capture was originally used. The files retain their upstream contents.

Laboratory transcripts, derived labels, predictions, model weights and fuzzing code are not included. Captures alone do not reproduce all results.
